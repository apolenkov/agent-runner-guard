# Design

Use web-tree-sitter 0.27.1 with tree-sitter-bash 0.25.1's distributed WASM. Parse once per interpretation, copy metadata and delete each tree; initialize the WASM language once per process. shell-quote 1.12.0 decodes only a single AST-confirmed static literal. No expansion, environment lookup, Bash evaluation, custom lexer or WASM compilation.

Direct argv is already tokenized and never joins into shell source. A shell invocation is recognized only for sh/bash/zsh and supported short options; a grouped option containing `c` consumes the next argv as the script, regardless of later positional arguments. Unsupported shell options yield unknown metadata.

Inspect simple command positions in program/list/subshell/pipeline nodes, with AST-separated static shell assignments and the existing bounded env/exec/nohup/nice/timeout wrappers. Only env operand context consumes assignment-looking argv; other executable positions retain those strings. Skip function bodies, conditional/loop bodies, substitutions and heredoc bodies. Literal quoted runner text is data. Recognize Devin `-p`, Pi, and Codex `exec` after verified value/boolean global options; the hook requires Pi `-p`. Unknown Codex options or option values, help/version and non-exec forms are unclassified.

Literal words may contain shell escaping, single/double quotes and literal concatenation. Expansions, substitutions, globs, tilde and unsupported word kinds have unknown values; they are never expanded. Dynamic prompt arguments may remain untouched inside a recognized runner command. Unknown path values never become watch-file or prompt-file identity.

Propagate cwd through successful literal `cd <path> &&` in order. `cd -` (including `cd -- -`) depends on OLDPWD; option-bearing or wrapper-assisted cd, assignments, dynamic command names and source/./eval/pushd/popd/builtin/command invalidate cwd. An inherited nonempty CDPATH makes searchable relative cd unknown; explicit ./ and ../ operands remain literal. The model assumes ordinary shell builtins, without alias/function overrides or inherited startup scripts; those are unsupported, not correctness claims. Unconditional cd, dynamic cd, unsupported state-changing syntax, OR branches and pipeline/subshell effects invalidate outward cwd. Subshell commands may still be classified but their inherited uncertain cwd is not invented. Resolve a relative redirect/prompt only with a known absolute cwd. Absolute literal paths remain usable. Resolve subshell stdout redirects at the subshell execution cwd and carry that resolved destination into supported children. Keep command-local redirect nodes pending through surrounding `&&` lists until reaching their command, where they override inherited stdout at the child execution cwd. Track the effective runner stdout destination (`>`, `>>`, `1>`, `1>>`, `&>`/`&>>`); descriptor duplication or dynamic destination can invalidate it. `/dev/null` is not watched. Redirection spans are omitted from shell lock fallback identity without removing quoted operators or losing argv boundaries.

Hook Pi injection uses the actual command-name end span and preserves every other source byte. Existing conservative `<<` policy retains no Pi injection anywhere in such a script. Unsupported constructs pass unchanged or retain unknown metadata; they are not claimed to model full shell execution or arbitrary cwd mutation by external programs.

Primary docs and registry evidence, exact scope, test-authoring and measured compatibility are preserved under the package-2 handoff.
